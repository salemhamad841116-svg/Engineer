- ترحيل `037_ui_builder`: جدول `studio_ui_builds` (19 عموداً: الحالة/الإصدار/الأب/البوابات/heal_used…) + عمود `contract_json` في telemetry الموجّه لإعادة تشغيل العقد.

## الحدود الصادقة

1. توليد LLM/Gemini الحقيقي غير مختبر (بلا مفاتيح في البيئة) — التحقق عبر `UI_LLM_MOCK=1` وحقن LLM؛ العقد والبوابات تعمل على المخرجات الحقيقية الشكل.
2. الكود المولَّد HTML/CSS/JS مكتفٍ (بلا CDN) ليعمل في iframe المعزول دون بناء؛ تصدير React/Tailwind والرابط الحي وشجرة النسخ الكاملة = المرحلة 4.
3. مكوّن `UIBuilderPanel.tsx` مفحوص بـ esbuild لكنه غير مركّب في الواجهة بعد (التركيب مع E2E بالمرحلة 4).
4. التدقيق يتطلب ثنائي Chromium على المضيف (`CHROMIUM_PATH` أو المسارات القياسية)؛ بغيابه تُعاد UNVERIFIED بصدق لا READY مزيّف.
5. ربط Brand Vault بالسحب والإفلات، حزمة الهوية (أيقونات/OG)، وقياس التكلفة لكل بناء = المرحلة 4 وفق جدول التوزيع المعتمد.
