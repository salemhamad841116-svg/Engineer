# محرك الأسئلة السريعة الاختيارية — Quick Clarifiers Engine (الملحق السابع، المرحلة 1)

## ما هذا؟

منظومة توضيح اختيارية تعمل **قبل** أي استدعاء مولّد مدفوع. عندما يكون طلب المستخدم غامضاً أو ناقص خانة حرجة، تظهر بطاقة أسئلة سريعة (بحد أقصى 3 أسئلة / قاعدة النقرة الواحدة)؛ وعندما تكون الثقة عالية والخانات مكتملة، يصمت المحرك تماماً ويمرّر الطلب فوراً.

**الضمانة الجوهرية — Zero-Spend Pre-Flight:** المحرك لا يملك أي اعتماد على مزوّد مدفوع إطلاقاً؛ التوضيح قبل التوليد مجاني بالبنية نفسها، لا بالانضباط.

## نطاق المرحلة 1 المُنفَّذ

| الطبقة | النطاق |
|---|---|
| 1 — الكشف وعتبات الثقة | كاملة (صامت ≥ 0.80 بخانات مكتملة، نشط 0.50–0.79 أو خانة حرجة ناقصة) |
| 2 — بنك الأسئلة الحتمي | النواة: فصل المسار (intent_track) + خانات الصور (aspect_ratio / lighting / protected_text / style) |
| 3 — الأسئلة الديناميكية + الكبت | النواة: كبت المُجاب مسبقاً + قناة LLM محلية (qwen) بتحقق Zod |
| 4 — Micro-UX | كاملة: ≤3 أسئلة، أيقونات، swatch_hex، شارات كلفة، إدخال "أخرى" المضمّن |
| 5 — الافتراضيات الذكية والتحكم | كاملة: توصية القطاع، 1-Click Skip، أنماط smart/guided/turbo |
| 7 — وراثة Brand Kit | النواة: القفل يكبت style/theme ويملأ preset/palette/seed مسبقاً |
| 8 — المترجم والحقن والمزامنة | النواة: Clicks→JSON بصفر استدعاء LLM + مزامنة سجل التوجيه الأصلي |
| 9 — السرعة والكاش وقاطع الدائرة | كاملة: ‎<15ms بنك، كاش SHA-256، قاطع 800ms → افتراضيات ذكية |

**مؤجل بقرار الملحق (لا يُبنى الآن):** الطبقات 6 و10 بالكامل، أسئلة الماسك المصغرة (مرحلة 2)، عرض توضيحات UI/القطاعات والمرفقات والتفرع الشرطي وشرائح ما بعد التوليد وربط ميزانية الهجين (مرحلة 3)، ذاكرة التفضيلات والقوالب السريعة والتحليلات (مرحلة 4 — جداولها مرجعية فقط).

## قاعدة البيانات — هجرة 039_quick_clarifiers

- `studio_clarifier_sessions` — صف لكل بطاقة: الحمولة كاملة، الحالة (`pending/resolved/skipped/auto_proceeded/timeout_bypassed`)، المصدر (`deterministic_bank/local_llm/cache_hit/circuit_breaker_skipped`)، زمن الاستجابة. عزل كامل بـ `owner_id`.
- `studio_clarifier_cache` — كاش SHA-256 للأسئلة الديناميكية: التكرار المطابق = `cache_hit` بصفر استدعاء LLM، مع عدّاد إصابات.

## المسارات الثلاثة (كلها خلف requireWorkspaceAuth، معزولة بالمالك)

| المسار | الوصف |
|---|---|
| `POST /api/studio/clarifiers/evaluate` | التقييم قبل التوليد. يعيد `{bypassed:true, reason, defaults}` أو `{bypassed:false, card}` بعقد Zod الكامل |
| `POST /api/studio/clarifiers/:id/resolve` | المترجم: 0 استدعاء LLM إثباتاً (`llm_calls:0`)، يحدّث `corrected_intent` في صف التوجيه **الأصلي** دون تكرار، ويعيد `enhancer_bindings` للحقن المباشر |
| `POST /api/studio/clarifiers/:id/skip` | تخطٍّ بنقرة واحدة: يمضي على الافتراضي الموصى به (توصية القطاع نفسها الظاهرة في البطاقة) ويسجَّل بصدق `skipped` |

## بوابات القبول (المُثبتة آلياً في quickClarifiersSuite — 18 اختباراً)

1. **«ابني لي متجر عطور»** → بطاقة بنك حتمية ‎<15ms‎ بصفر إنفاق API، سؤال المسار أولاً بشارات 1/2/4 كريديت، وتوصية «المتجر الكامل» لقطاع المتاجر.
2. **«واجهة تداول داكنة للجوال»** → theme وplatform يظهران في `suppressed_slots` ولا يُسأل عنهما؛ وقفل Brand Kit يكبت style/theme ويملؤها مسبقاً.
3. **الشارات والتخطي:** swatch_hex بصيغة ‎`#RRGGBB`‎، recommended، cost_badge، 1-Click Skip، وتجاوز turbo الفوري.
4. **الحسم:** 0 استدعاء LLM + JSON مُتحقق بـ Zod + تحديث سجل التوجيه الأصلي + ربط المُحسِّن (`custom_text_input` → `protected_brand_text` حرفياً).
5. **الديناميكي:** أول طلب = `local_llm` (نداء محلي واحد بصفر دولار)، التكرار = `cache_hit` بصفر نداءات، ‎>800ms أو JSON فاسد = `circuit_breaker_skipped` → افتراضيات ذكية مسجلة `timeout_bypassed`.

## قرارات هندسية بارزة

- **`protected_text` لا يُكشف آلياً** — سؤال «هل يوجد اسم مكتوب يظهر حرفياً؟» يبقى مطروحاً في مسار الصور لأن نيّة النص لا تُستنتج حتمياً بأمان.
- **Skip يمضي على التوصية نفسها** — `defaultsFor` يفضّل `SECTOR_RECOMMENDATIONS[sector].intent_track` عند غياب النية، فلا تناقض بين ما أوصت به البطاقة وما يبنيه التخطي.
- **مزامنة التوجيه في الصف الأصلي** — يُعاد استخدام عمود `corrected_intent` الموجود في `studio_routing_telemetry`؛ لا صفوف مكررة ولا انحراف مخطط.
- **إصلاح تكاملي:** إضافة `/api/studio/` إلى `PROTECTED_API_PREFIXES` في `workspaceAuth.js` — بدونها كان الوسيط يمرّر كل مسارات الاستوديو دون هوية (خطأ 500 لكل المسارات القديمة والجديدة في التشغيل الحي).
