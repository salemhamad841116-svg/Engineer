# محسّن الأوامر الخلفي (Prompt Enhancer Engine) — المرحلة 1

**النطاق:** الملحق الرسمي «المعمارية الكاملة لمحسّن الأوامر الخلفي — 6 طبقات / 24 ميزة فرعية» ضمن حزمة المرحلة 1.
**الحالة:** منفَّذ ومختبَر فعلياً — 18/18 اختباراً × 4 تشغيلات متتالية مستقرة + كامل تراجع المنصة أخضر.

---

## 1. ما الذي بُني

وحدة مستقلة في `server/studio/enhancer/` من 9 ملفات، تُكمل الأمر الخام للعميل إلى عقد مهيكَل معتمد قبل أي استدعاء مدفوع:

| الطبقة | الميزات | التنفيذ |
|---|---|---|
| 1. التطبيع وحماية الكيانات | تصحيح إملائي (سحراء→صحراء)، توحيد همزات/ألف مقصورة/تاء مربوطة، فك اللهجات (مع تحمّل سابق الواو)، قفل الكيانات الحرفية (علامات اقتباس + أنماط «باسم» + **استدلال العلامة غير المُقتبسة** بعد أسماء الأعمال مع حارس ضد الإيجابيات الزائفة)، كشف الاتجاه RTL/LTR | `enhancerNormalize.js` — محلي حتمي $0 |
| 2. التوسيع والسياق | ملء الفجوات (طلب من 3 كلمات → مواصفة مكتملة)، دمج دلتا المتابعة فوق آخر عقد معتمد في الجلسة (مع **وراثة الكيانات المحمية**)، المواءمة الثقافية (خليجي/دولي)، حل التناقضات (شمس+ليل → الليل يغلب كإعداد مع تحويل العنصر المتعارض وتوثيق القرار) | `enhancerContext.js` + قناة توسيع اختيارية عبر qwen2.5:7b |
| 3. الهندسة المزدوجة | مسار الصور: عدسة/زاوية/إضاءة/خامات/عمق ميدان حسب الوضع، مساحة سلبية آمنة للنص (يمين RTL / يسار LTR)، صياغة إنجليزية دقيقة مع النص المحمي حرفياً دون ترجمة | `enhancerTracks.js` |
| 4. حقن الأوضاع والهوية | دمج قالب الوضع مع إزالة التكرار، توزين القوة (subtle يسقط اللاحقة / strong يضيف التعزيز)، ربط لوحة الهوية + style_seed + المرجعية، توليد negative_prompt ديناميكي لكل فئة وواعٍ بالاتجاه | `enhancerPresets.js` |
| 5. التكيّف والأمان والبدائل | محوّل صياغة المزوّد (gemini سردي / fal وسوم مكثفة + سياقا inpaint/outpaint للمرحلة 2)، إعادة صياغة آمنة قبل الإرسال (تفادي الرفض الخاطئ، موثقة)، تنويع بدائل 2–4 بفروقات زاوية/إضاءة حقيقية حتمياً | `enhancerDialects.js` |
| 6. التحقق والكاش والتحسين الذاتي | عقد Zod صارم (المخطط الرسمي للملحق حرفياً)، كاش SHA-256 يقصّر الدائرة **قبل** أي نداء LLM، سُلّم إعادة محاولة: محلي → إعادة واحدة → gemini-flash → استمرار حتمي صادق، تحسين ذاتي عند فشل OCR (قيود تشديد موثقة، محاولة واحدة)، سجل قياس كامل في SQLite + معاينة/تعديل يدوي (Pro Override) | `enhancerSchema.js` + `enhancerStore.js` + `promptEnhancerEngine.js` |

## 2. عقد المخرجات

يطابق مخطط الملحق الرسمي ويُتحقق عبر Zod قبل أي استخدام: `track, provider_dialect, direction, protected_brand_text, preset_id, preset_intensity, enhanced_prompt, negative_prompt, variation_prompts[], retry_refinement_applied, cache_hit`.

## 3. قاعدة البيانات والمسارات

- **ترحيل 038** (`038_prompt_enhancer`): جدولان بتصميم منفصل عن قصد —
  - `studio_prompt_enhancements`: دفتر قياس **إلحاقي فقط** (كل تشغيلة موثقة: خام/محسّن/مزوّد المحرك/احتياط/تجاوز/تحسين/زمن).
  - `studio_prompt_cache`: مؤشر كاش واحد لكل `UNIQUE(owner_id, fingerprint)` — البصمة تغطي كل مدخل مؤثر في المخرج (بما فيه الجلسة، ومعرّف العقد السابق **فقط عند تطبيق دلتا فعلياً** حتى لا ينكسر الكاش).
- **مساران** خلف المصادقة وبعزل المستأجر:
  - `POST /api/studio/enhance` — العقد الكامل + مفاتيح توافقية قديمة (`prompt_en/negative/overlay_texts`). يربط لوحة Brand Lock تلقائياً عند تمرير `project_id`.
  - `GET /api/studio/enhance/telemetry` — دفتر القياس (خام مقابل محسّن، زمن، حالة كاش/احتياط/تجاوز).
- **تكامل التوليد:** `generateStudioAsset` يقبل `enhancerContract` و`variationIndex` — البديل الثاني يستخدم `variation_prompts[0]` فعلياً، وعند فشل بوابة OCR تُستدعى `refineForRetry` (بدل اللاحقة الثابتة) وتُسجَّل في الدفتر.

## 4. الاختبار الفعلي (18/18 × 4 تشغيلات)

الجناح `server_backend/tests/promptEnhancerEngineSuite.test.js` يغطي مجموعات القبول الست من الملحق حرفياً، وأبرز البراهين:

- جملة القبول الرسمية: تصحيح «سحراء»، تعيين اللهجة، ‏`direction: rtl`، و‏«قهوة الأصالة» حرفياً في `protected_brand_text` (P1) + حُرّاس الإيجابيات الزائفة (P2).
- متابعة «خلّ الإضاءة ليلية» تندمج فوق العقد السابق مع بقاء اسم المتجر والصحراء (P4).
- «شمس ساطعة في ليل مظلم» تُحل بلا تناقض والقرار موثق (P5).
- كاش البصمة: التكرار يرجع `cache_hit: true` بعدّاد يثبت **صفر نداءات LLM** (P13).
- JSON مكسور من المحلي مرتين ← إعادة واحدة ← ‏gemini-flash‏ ← اجتياز Zod ودمج التوسيع في الأمر (P14)؛ وعند تعثر كل القفزات: استمرار حتمي صادق بعقد سليم (P15).
- فشل OCR مُحاكى في خط التوليد الحقيقي ← ‏`retry_refinement_applied: true`‏ وقيود التشديد في المحاولة الثانية وصف قياس كامل (P16+P17).
- بوابة اللغة: صفر حروف عربية في ملفات المحرك (العربية في `i18n/enhancerLexicon.js` والـ fixtures فقط) (P18).

**التراجع الكامل أخضر:** smartStudio 25/25، presets 14/14، router 15/15، imageMode 10/10، uiBuilder 17/17، ترحيلات من الصفر ✅. البوابة الجديدة **8j** أُضيفت إلى `verify-build.mjs`.

## 5. الحدود الصادقة

- **مسار الواجهات (ميزة 10) ومغلّف قيود الكود (ميزة 18)** مؤجلان للمرحلة 3 حسب جدول الملحق — يُرجع المحرك غلافاً موسوماً `deferred` بصراحة بدل تزوير مواصفة.
- **ربط Brand Kit الكامل (ميزة 15)** بنطاق المرحلة 1: لوحة Brand Lock + style_seed + المرجعية؛ خزنة الهوية الشاملة مرحلة 4.
- **توسيع qwen2.5:7b الحقيقي غير مُتحقق في بيئة الاختبار** (لا أسطول هنا) — سُلّم إعادة المحاولة والاحتياط مُثبت بجواسيس مُحقَّنة، والمسار الحتمي يعمل بلا أي نموذج. في الإنتاج تُربط المحوّلات عبر `defaultRouterLlm()` (نفس نمط الموجّه).
- الاعتمادية الجديدة الوحيدة: **zod** (مضافة إلى package.json).
